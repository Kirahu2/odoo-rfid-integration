# Odoo RFID Integration — SPIDERS RFID

Integrate **UHF RFID hardware** (handheld terminals, fixed readers, warehouse gate portals) with **Odoo ERP** inventory — real-time stock counting, receiving, and shipping verification.

## Resources

- **Solution overview & integration guide**: <https://www.spidersrfid.com/en/odoo-rfid/>
- **Demo videos (Odoo RFID Integration playlist)**: <https://www.youtube.com/playlist?list=PLfLhtSVBU8rs>

## What you'll find at the links above

- How UHF RFID handhelds and portal readers connect to Odoo via a lightweight middleware
- Real-time stock.quant updates driven by RFID tag reads (EPC to SKU mapping)
- Warehouse inventory count demo: hundreds of tags read per second, synced into Odoo
- Security gate / portal reader demo for dock-door and exit control
